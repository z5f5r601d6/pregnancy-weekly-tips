# 【科普】养娃之警惕“大胖儿”

> 更新时间：2026-09-17 (UTC+8)

儿童肥胖症是体内脂肪过度堆积，导致体重显著高于同龄、同性、同身高儿童标准的慢性疾病。数据显示，我国6—17岁儿童超重肥胖率近20%，且逐年上升，肥胖不再是“可爱”，而是健康“警报器”。

**01**

**如何识别**

**BMI计算法：**体重（kg）÷身高²（m²），对照《中国儿童BMI百分位表》：≥P85为超重，≥P95为肥胖。

**肉眼信号：**双下巴、腹部赘肉堆积、运动后气喘加重；衣服码数持续增长远超同龄人。  

**02**

**认识误区 **

1、“小时候胖没关系，长大自然瘦” → 70%肥胖儿童成年后仍超重。

2、“胖娃身体壮”→ 肥胖儿童免疫力可能更低，更易生病。

**03**

**肥胖危害**

**1、身体健康威胁**

代谢异常：胰岛素抵抗、2型糖尿病、高血脂、脂肪肝。  

心肺功能下降：运动耐力差、哮喘风险增加。  

骨骼肌肉问题：关节负荷过重（如扁平足、膝内翻）、青春期提前。  

**2、心理与社会影响 **

自卑、社交退缩、校园霸凌风险升高；长期肥胖可能延续至成年，增加心血管疾病、癌症等慢性病风险。

**04**

**饮食篇：吃饱又吃好  **

**三减原则：**减糖饮料、减油炸零食、减精制主食。

彩虹餐盘计划：每天吃够5种颜色蔬果（如红番茄、绿菠菜、黄玉米）。  

**吃饭口诀：**先喝汤→再吃菜→最后吃肉和饭；细嚼慢咽（每口嚼20下），避免边吃边看屏幕。

**05**

**运动篇：每天动起来**

**趣味运动套餐（每天60分钟）：**上学快走10分钟 + 课间跳绳5分钟 + 亲子舞蹈15分钟 + 睡前拉伸5分钟 。 

**家务运动：**擦地板=全身锻炼，晾衣服=踮脚长高训练。

**06**

**生活习惯篇**

**睡足觉：**小学生每天10小时，避免熬夜。  

**屏幕限时：**每天≤1小时，用亲子游戏替代手机动画 。 

**07**

这些情况速就医

1、体重突然暴涨 。

2、颈部/腋下出现深色皮肤（黑棘皮症，提示胰岛素抵抗）。  

3、男孩乳房发育、女孩月经初潮早于8岁。
